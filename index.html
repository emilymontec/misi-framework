Una base PHP
[ sin dependencias ]
para sistemas de gestión.

PHP 8.1+· MySQL / MariaDB· Sin Composer obligatorio

Misi es una base de desarrollo pensada para construir rápido sistemas administrativos de pequeños negocios — sin reinventar routing, autenticación, CSRF o validación en cada proyecto nuevo. Sin ORM. Sin Node.js en producción. Nada que no puedas leer y entender en una tarde.

[N.01/04] > QUÉ TRAE MISI

/ Menos boilerplate.
Más código que sí importa. /

Trece fases construidas y probadas de punta a punta contra MySQL real — no solo diseñadas en el papel.

■ EMPEZAR AHORA
// 001

Sin ORM, SQL explícito

Un wrapper delgado sobre PDO: select(), insert(), transaction(). Prepared statements siempre. Nunca adivinas qué SQL se ejecutó de verdad.

// 002

Auth y CSRF de fábrica

Sesiones seguras, roles y permisos simples, protección CSRF automática en cada ruta que muta estado. No es opcional agregarlo después.

// 003

Validación completa

18 reglas listas — required, email, unique, image, max_size... con errores estructurados por campo.

// 004

Storage sin sustos

Subida de archivos con MIME real, nombre generado y bloqueo de path traversal — verificado con un intento de ataque real.

// 005

Módulos reutilizables

Empaqueta rutas y migraciones propias en modules/. Descubrimiento automático, sin tocar el core.

// 006

CLI con generadores

bin/biz: serve, migrate, y make:controller/model/service/repository/module. Cero dependencias externas.

[N.02/04] > PRIMEROS PASOS

/ De cero a servidor
corriendo en 5 pasos. /

  1. 1 Descarga o clona el proyecto base y entra a la carpeta.
  2. 2 Copia .env.example a .env y completa tus credenciales de MySQL.
  3. 3 Corre las migraciones — crean las tablas de usuarios, roles y permisos.
  4. 4 (Opcional) Siembra datos demo: un usuario admin con changeme como contraseña.
  5. 5 Levanta el servidor de desarrollo y abre localhost:8000. 
# 1-2. preparar el entorno
$ cp .env.example .env
$ nano .env   # DB_DATABASE, DB_USERNAME, DB_PASSWORD

# 3-4. base de datos
$ php bin/biz migrate
Migrado: 001_create_users_table.php
Migrado: 002_create_roles_and_permissions.php
Migrado: 003_create_uploads_table.php

$ php bin/biz db:seed
Usuario admin demo creado (admin@misi.test / changeme)

# 5. arrancar
$ php bin/biz serve
Misi escuchando en http://127.0.0.1:8000
[N.03/04] > DE RUTA A RESPUESTA

/ Un endpoint completo,
sin ceremonia. /

Ruta, validación y guardado en base de datos — así se ve un endpoint típico en un proyecto real sobre Misi.

routes/web.php 
use App\Http\Controllers\CustomerController;

$router->get('/customers', [CustomerController::class, 'index']);

$router->post(
    '/customers',
    [CustomerController::class, 'store'],
    ['auth', 'csrf']
);
app/Http/Controllers/CustomerController.php 
use Misi\Http\JsonResponse;
use Misi\Http\Request;

final class CustomerController
{
    public function store(Request $request): JsonResponse
    {
        $data = app()->validator()->validate($request->all(), [
            'name'  => ['required', 'max:150'],
            'email' => ['required', 'email',
                        'unique:customers,email'],
        ]);

        $id = app()->database()->insert('customers', $data);

        return JsonResponse::success(['id' => $id], 'Cliente creado', 201);
    }
}
[N.04/04] > BIN/BIZ

/ Un CLI, sin dependencias,
que hace lo necesario. /

Nada de Symfony Console — un solo script PHP que despacha comandos. Generadores incluidos, sin sobrescribir nada por accidente.

$ php bin/biz serve                  # servidor de desarrollo
$ php bin/biz migrate                 # ejecuta migraciones pendientes
$ php bin/biz migrate:status           # qué corrió, qué falta
$ php bin/biz migrate:rollback          # revierte el último lote
$ php bin/biz db:seed                    # siembra datos iniciales

$ php bin/biz make:controller Customer     # app/Http/Controllers/CustomerController.php
$ php bin/biz make:model Product            # app/Models/Product.php
$ php bin/biz make:service OrderProcessing   # app/Services/OrderProcessingService.php
$ php bin/biz make:repository Product          # app/Repositories/ProductRepository.php
$ php bin/biz make:module Inventory             # modules/Inventory/ completo
